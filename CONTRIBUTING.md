# Contributing to Awesome MCP Servers for Sales Automation

First off, thank you for considering contributing to this list! It's people like you that make it a valuable resource for the community.

Please take a moment to review these guidelines before submitting a pull request.

## Guidelines

1. **Only Real, Functional MCP Servers** - We only accept servers that actually work, have a public repository or service endpoint, and are directly useful for sales automation, outreach, lead generation, CRM, databases, or scheduling workflows.
2. **Minimum Popularity** - The tool's GitHub repository must have at least 100 stars to be accepted. Pull requests for repositories below this threshold will be closed. Official implementations by the core product team (e.g., HubSpot, Salesforce, Cal.com) are exempt from this requirement.
3. **Formatting** - Please keep the formatting consistent:
   - Format: `[Tool Name](github-link) - One line description. ⭐ if notable`
   - Description should start with a capital letter and end with a period.
   - Limit description to one concise line focusing on what the tool does.
4. **Alphabetical Order** - Within each category, please insert new tools alphabetically to keep the list clean and easy to scan.
5. **Awesome-List Quality** - Ensure your description is objective, clear, and avoids marketing speak or hype.
6. **Stars (⭐)** - Stars are reserved for official implementations by the core product teams (e.g., Anthropic, HubSpot, Salesforce, Microsoft, Cal.com) or community projects with 500+ GitHub stars.

## How to Contribute

1. Fork the repository.
2. Create a new branch with a descriptive name (e.g., `add-mytool-mcp`).
3. Make your changes in `README.md`.
4. Commit your changes with a clear message (e.g., `Add mytool-mcp to Email Automation`).
5. Push your branch and submit a pull request against the main branch.
6. Provide a quick summary in the pull request explaining what the tool is and why it belongs on this list, including the tool repository's current star count.

## Support the Project

If this list helped you, consider giving this repository a GitHub star (the star button at the top of the page). It is completely optional and has no effect on whether your pull request is accepted, but it helps more people find the list.

Thank you for your contribution!
